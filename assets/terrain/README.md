# Terrain runtime assets

- ground/: retained bush_tile and rock_tile assets, currently unused.
- plants/decorative/: NE/NW/SE/SW walkable slowing plants.
- plants/fruiting/: bush1, bush2, shrub used by configurable fruit plants.
- plants/cacti/: cactus, currently placeholder dragon-fruit plant art.
- rocks/: pebble sprite used for dense walkable slow patches.

Use res:// paths matching these folders. Preserve PNG import settings when moving assets. Original editable/source packs belong in assets/source; item icons remain in assets/items. Assets are displayed with nearest-neighbor filtering and texture regions where needed, without modifying their PNG pixels.
